MILESTONE 2 SUMMARY
===================

Status: Complete (October 24, 2026). Planned October 11, 2026; the original
plan is in git history.

Objective
---------
Show upcoming Georgia Tech events as clickable pins on a Google Map of
campus.

Done when: map.html shows the next 10 events as correctly placed pins with
popups, lists every event that can't be pinned for the same time frame, and
the location match rate is known. All three are true.

What Was Accomplished
---------------------

1. Event data from GT's RSS feeds (scraper/gt_calendar_rss.py)
   - Reads the category feeds listed at https://calendar.gatech.edu/rss-feeds
     instead of scraping the calendar page (see Key Decisions)
   - Parses each item's labeled sections: event time, location, fee,
     extras (free food), invited audience, related links, categories
   - Converts times from UTC to Atlanta time; flags all-day events
   - Keeps each event once when it appears in several feeds, keeps only
     events that haven't ended, and merges events GT posted twice under
     different links (same name, start time and location)
   - Sanity check: stops with an error and keeps the old events.json if no
     events are found or most have no name or location
   - Identifies itself honestly in its User-Agent and waits 2 seconds
     between feeds

2. Building list (data/gt_buildings.json)
   - 57 places with keywords and coordinates, every one checked by eye on
     the map by the project owner (source: google_maps)
   - Places too far away for the campus map (e.g. R. Randall Rollins at
     Emory) are marked off_campus

3. Location matching (locate.py)
   - Matches whole-word building keywords inside free-text locations
     ("Room 357, Clough Undergraduate Learning Commons" -> Clough)
   - Labels every event: matched, off_campus, unmatched, online,
     no_location
   - Prints the match rate and the most common unmatched locations, which
     serve as the to-do list for new buildings

4. Map page (map.html)
   - Google Map of campus with one numbered pin per building; clicking a
     pin lists that building's events (name linked to the GT page, time,
     location, free-food tag)
   - Side panel "Not on the map" listing online, off-campus, unmatched and
     no-location events for the same time frame as the pins, so no event
     is hidden just because it has no pin
   - "Show all building points" draws every building, colored by where its
     coordinates came from, for checking them
   - API key lives in config.js (gitignored) and is restricted to
     localhost

Results (October 24, 2026)
--------------------------
- 8 of 10 listed feeds work; 213 upcoming events after merging duplicates
- 14 upcoming events list free food (from the feed's own Extras field)
- Locations: 89 pinned, 1 off campus, 15 unmatched, 79 online,
  29 with no location
- Match rate for in-person events: 86% (up from 80% at the start)
- The 15 unmatched are mostly facilities staff rooms ("Area 1 Break
  Room", "Holland Plant Control Room") and off-campus places with no
  coordinates; they appear in the map's list

Key Decisions
-------------
- No LLM for calendar.gatech.edu. The data is already structured, so plain
  parsing gives exact results; an LLM would add cost and randomness. It may
  still help later with messy sources, after measuring what rules miss.
- RSS feeds instead of scraping the calendar page (October 22). The feeds
  are what GT publishes for reuse, while automated scraping of the page
  might go against its policies. The cost: the feeds covered only ~40% of
  the page's upcoming events at first (see Open Issues). The old scraper
  is kept in scraper/gt_calendar_scraper.py for reference, unused.
- Every event in the time frame must be visible. Events that can't be
  pinned go in a list rather than being dropped, and coordinates are never
  guessed for places whose location isn't known (e.g. Chapin, Holland
  Plant).
- One pin per building, so events in the same building don't stack.

Issues Found in GT's Feeds
--------------------------
Reported to GT by email on October 24; awaiting a reply.
- "Student sponsored" (term 19) returns a PHP out-of-memory error
- "Special event" (term 17) is empty
- The "Seminar/Lecture/Colloquium" link points to term 14
  (Conference/Symposium); the real seminar feed, term 16, was found by ID
  and added
- The "Institute/Academic/Religious" link leads to a feed titled
  "holidays and observances"
- Events with no category are in no feed
- The same event is sometimes posted twice under different links (now
  merged)
The email also asked whether GT has an official list of building
coordinates, and whether reading the feeds this way is acceptable.

Open Issues
-----------
- Coverage: student-sponsored and uncategorized events are missing until
  GT fixes the feeds or adds an all-events feed.
- Time frame: the map shows "the next 10 pinned events", so its window
  varies (about 3 days on October 24). Milestone 3's date/time filter
  replaces this.

Key Files

- locate.py: matches events to buildings, prints the match rate
- map.html: the map page
- config.example.js: template for config.js (API key, gitignored)
- docs/map_milestone2.png: screenshot used in the README
